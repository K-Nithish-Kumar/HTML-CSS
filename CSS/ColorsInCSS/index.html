Colors In CSS

Named Colour

color: green;

color: blue;

color: orange;

RGB color

color: rgb(255,255,255); -> r - red, g - green, b - blue and ranges from 0 t0 255. 255 means full colour, 0 means no colour

RGBA color -> same as RGB add transparency and its range from 0 to 1

color: rgba(255,255,255,0.4)

Hex Color

color: #FFFFFF -> Hex is denoted using 6 characters it is same as rgb each 2 character represent one channel. 1st 2 character represent red channel and next 2 represent green channel and next 2 represent yellow channel. Ranges from 0 to 9 and A to F
